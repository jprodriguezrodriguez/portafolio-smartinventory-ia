Un prototipo en evolución

Una primera base para explorar la gestión del negocio y preparar las siguientes etapas de desarrollo.

Qué hay en el prototipo

El código en Python, Flask y SQLite incluye registro de ventas, consulta y ajuste de existencias y una vista de estimación de agotamiento.

Para cada producto con ventas recientes, estima cuántos días durarán las existencias dividiendo la cantidad disponible entre el promedio diario de ventas. El cálculo considera ventas dentro de una ventana de hasta 14 días.

El modelo de aprendizaje automático previsto y su comparación con el promedio móvil mediante MAE y RMSE siguen pendientes de desarrollo y evaluación.
